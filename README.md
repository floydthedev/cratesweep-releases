# CrateSweep Releases

Official release downloads for **[CrateSweep](https://cratesweep.com)** — a macOS app that helps DJs find and safely remove duplicate tracks from their Serato DJ libraries.

## Download

- **Latest version (stable link):** [CrateSweep.dmg](https://github.com/floydthedev/cratesweep-releases/releases/latest/download/CrateSweep.dmg)
- **All versions:** see the [Releases](https://github.com/floydthedev/cratesweep-releases/releases) page
- **Website download page:** [cratesweep.com/download](https://cratesweep.com/download)

The stable link above always points at the newest release, so it's safe to bookmark or share.

## Release notes

Each release includes user-facing notes — new features, improvements, and fixes written for DJs, not developers. The same notes power the "What's new" section on the [download page](https://cratesweep.com/download).
